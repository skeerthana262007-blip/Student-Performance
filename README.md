# Student Performance Prediction

## Project Overview
This project predicts student performance using Machine Learning. It includes data preprocessing, exploratory data analysis (EDA), feature encoding, model training, and performance evaluation using Logistic Regression.

## Features
- Data Cleaning
- Missing Value Handling
- Exploratory Data Analysis (EDA)
- Label Encoding
- Logistic Regression Model
- Accuracy Evaluation
- Confusion Matrix
- Classification Report
- Cross Validation

## Technologies Used
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Dataset
The dataset contains student information such as:
- Study Hours per Week
- Attendance Rate
- Previous Grades
- Participation in Extracurricular Activities
- Parent Education Level
- Passed (Target Variable)

## Project Workflow
1. Load Dataset
2. Data Preprocessing
3. Handle Missing Values
4. Perform EDA
5. Encode Categorical Features
6. Train Logistic Regression Model
7. Evaluate Model
8. Save Predictions

## Results
The model was evaluated using:
- Accuracy Score
- Confusion Matrix
- Classification Report
- Cross Validation
